# Alzheimers-Disease-Classification

## 📌 Project Overview
This project focuses on analyzing patient health and demographic data to classify whether a patient is likely to have Alzheimer's disease. The project involves data preprocessing, exploratory data analysis (EDA), feature analysis, and machine learning model development.
The goal is to understand the factors associated with Alzheimer's disease and build a machine learning classification model that can predict the diagnosis based on patient-related features.

## 🎯 Objectives
* Perform data cleaning and preprocessing.
* Explore the dataset using Exploratory Data Analysis (EDA).
* Analyze relationships between patient features and Alzheimer's diagnosis.
* Prepare the dataset for machine learning.
* Build and evaluate classification models.
* Compare model performance using standard evaluation metrics.

## 📊 Dataset
The dataset contains information about Alzheimer's disease patients, including demographic, lifestyle, medical, and clinical features.

**Dataset Details:**
* Number of Records: 2,149
* Age Range: 60–90 years
* Target Variable: Alzheimer's Disease Diagnosis
* Target Type: Binary Classification

> **Note:** The dataset is used for educational and machine learning purposes and should not be considered a medical diagnostic tool.

## 🔍 Exploratory Data Analysis
The following EDA techniques were performed:

* Categorical feature analysis
* Outlier detection using boxplots

## ⚙️ Data Preprocessing
The following preprocessing steps were performed:
* Data cleaning
* Handling missing values
* Feature selection
* Encoding categorical variables where required
* Feature scaling
* Splitting data into training and testing sets

**Train-Test Split:**
* Training Samples: 1,719
* Testing Samples: 430


## 🤖 Machine Learning
This project uses supervised machine learning classification techniques to predict Alzheimer's disease diagnosis.
The models were trained using the processed dataset and evaluated using standard classification metrics.

### Evaluation Metrics
* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
